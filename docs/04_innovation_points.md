## 五大创新点

### 🌟 创新点 1: 工作站可复现的 WRF 替代方案

**核心**: 用多源数据融合 + 神经算子学习取代 WRF 物理模拟

**证据**:
- 文章一需 50,000+ CPU·hr（超算）
- 本框架 < 500 CPU·hr（工作站）
- 精度损失 < 5%（RMSE 0.71 vs 0.61 K）

**学术意义**:
- 让任何研究者都能开展高分辨率城市气候研究
- 大幅降低 LCZ 研究的硬件门槛
- 推动开放科学

**联网验证**:
- ✅ Fourier Neural Operator 已被证明在流体力学等领域有效
- ⚠️ 但**首次**用于城市微气候多源融合
- ⚠️ **首次**结合 LCZ-aware attention

### 🌟 创新点 2: 拓扑数据分析揭示 LCZ 隐藏几何

**核心**: 用持续同调（Persistent Homology）刻画 LCZ 亚类的"热场拓扑指纹"

**问题**: 文章一用 k-means 聚类得到 26 亚类，但
- 仅基于"平均值/方差"——丢失几何结构
- 无法识别"形状不同但数值相近"的亚类

**本框架方法**:
- Cubical Complex 持续同调
- β₀ (连通分量), β₁ (一维洞)
- Persistence Diagram → 26 亚类指纹

**期望发现**:
> "LCZ 1A 与 LCZ 1B 平均 UTCI 仅差 0.3°C，但拓扑指纹揭示
> LCZ 1A 是'多冷岛被环绕'结构（β₁ 高），
> LCZ 1B 是'热岛连通山脊'结构（β₀ 高）。
> 这是文章一无法发现的几何分类。"

**联网验证**:
- ✅ TDA 已用于 LCZ 卫星图像分类（[ScienceDirect 2021](https://www.sciencedirect.com/science/article/pii/S2667010021003334)）
- ⚠️ **但用于 UTCI 场拓扑分析、且与 LCZ 亚类绑定** = 真正空白

### 🌟 创新点 3: 符号回归自动发现城市气候方程

**核心**: 用 PySR 进化算法从数据自动发现解析方程

**问题**:
- 黑箱 ML 不可解释
- 经典经验公式（如 Oke 1976）过于简化
- SHAP 仅给重要性排序，不给方程

**本框架方法**:
```
Input:  100m 网格的 UMPs (10 维) + UTCI 标签
Output: 多个候选方程（按精度-复杂度的 Pareto 前沿）
约束:   物理量纲一致、单调性合理
```

**期望发现**:
```
方程候选:
   UTCI ≈ 28 + 4·BSF − 8·SVF + 0.3·sqrt(BV) − 0.05·PSF·MBH
                    ▲              ▲                  ▲
                    │              │                  │
              建筑密度正影响   天空可视度负影响   建筑-透水面交互（新发现）
```

**学术意义**:
- 首次用 AI 自动发现城市热舒适解析方程
- 推动 AI4Science 在城市气候领域的落地
- 发现可被领域专家解读、引用的明确公式

**联网验证**:
- ✅ PySR 用于物理学、生态学、地磁学（Cranmer et al. 2023）
- ⚠️ **未见用于城市微气候/UTCI/LCZ 任何文献**

### 🌟 创新点 4: 非线性因果推断颠覆 SHAP 相关性

**核心**: 用 Convergent Cross Mapping (CCM) 检验非线性因果

**问题**:
- SHAP 仅给"统计相关"——可能被混淆变量误导
- Granger 因果假设线性可加——城市气候是非线性的
- 文章一无法回答"如果干预 SVF +0.1，UTCI 真实变化是多少"

**本框架方法**:
- CCM (Sugihara 2012, Science)：非线性时序因果
- DML (Chernozhukov 2018)：双重 ML 因果效应
- 反事实推断：估计干预效应

**期望发现**:
> "SHAP 显示 BSF 对 UTCI 重要性 = 12.1%，
> 但 CCM 揭示 BSF → UTCI 的真实因果强度 ρ_CCM = 0.67，
> 显著高于 SHAP 暗示的相关性。
> 这意味着以往基于 SHAP 的政策建议低估了密度调控的潜在收益。"

**联网验证**:
- ✅ CCM 用于美国城市热-污染因果（[IOP 2026](https://iopscience.iop.org/article/10.1088/1748-9326/ae53fd)）
- ⚠️ **CCM + LCZ 亚类 + UMPs** 组合 = 真正空白

### 🌟 创新点 5: 跨城市迁移学习

**核心**: 一次训练 → 多城应用

**问题**:
- 文章一: 每个城市需单独跑 WRF（重新训练）
- 现有 ML 模型: 跨城市泛化能力弱

**本框架方法**:
- FNO 学习"算子"而非"权重"——分辨率不变
- LCZ-aware attention 内化 LCZ 类型差异
- 跨城迁移学习: 仅微调注意力层

**期望产出**:
- 深圳模型 → 广州/东莞/佛山/香港
- 每个目标城市仅需少量站点微调
- 精度损失 < 15%

**联网验证**:
- ✅ 跨城市迁移用于交通预测（[arXiv 2022](https://arxiv.org/pdf/2206.00007)）
- ⚠️ **跨城市 UTCI 迁移** = 未见
